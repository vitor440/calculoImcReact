## Como Executar

1. Clone o repositório
```
 git clone https://github.com/vitor440/calculoImcReact.git
```
2. abra o terminal dentro da pasta que contém o src (learning_react)
3. execute no terminal o comando 'npm install'
```
 npm install
```
4. Caso ocorra algum erro de vulnerabilidade execute 'npm audit fix'
```
 npm audit fix 
```
5. depois execute o comando 'npm run dev'
```
 npm run dev
```
6. A aplicação ficará disponível na porta 5173 (localhost:5173)
