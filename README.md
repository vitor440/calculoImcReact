## Como Executar

1. abra o terminal dentro da pasta que contém o src
2. execute no terminal o comando 'npm install'
3. depois execute o comando 'npm run dev'
4. A aplicação ficará disponível na porta 5173 (localhost:5173)

```
npm intall
npm audit fix # caso encontre algum erro de vulnerabilidade
npm run dev
```
